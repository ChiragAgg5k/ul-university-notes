1. Partitioning: domain (data) decomposition
    • n + 1 tasks (n = 10m, 100m, 500m)
    • the same operation for every task
  2. Communication: none during the computation
    • one global sum reduction at the end
    • a tree reduction takes ⌈log2 n⌉ rounds, e.g. 24 for 10m
  3. Agglomeration: contiguous blocks
    • p blocks of about (n − 1) / p points each (p = number of threads)
  4. Mapping: static mapping
    • the tasks are uniform
