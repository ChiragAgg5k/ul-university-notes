Partitioning is the first step of Foster's methodology: divide and conquer.

The function to integrate is f(x) = e−x · sin(x). Since the computation is already confined, the problem is split by domain (data) decomposition.

The domain is divided into n + 1 sample points, xi = a + i · h, where:

  • xi = x-coordinate of the i-th point
  • a = start of the interval
  • b = end of the interval
  • n = number of trapezoids
  • h = width of each strip
  • i = index
  • Each task is independent: it is just a computation.
  • The tasks are uniform: each one evaluates e−x and sin, then multiplies them.
  • Special case: the endpoints i = 0 and i = n have weight ½.
