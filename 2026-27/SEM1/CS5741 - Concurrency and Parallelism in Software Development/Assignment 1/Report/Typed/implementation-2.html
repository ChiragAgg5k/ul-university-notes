Synchronisation

  • None is needed, as all tasks are independent.
  • No locks and no atomics are used.
  • Only join() is needed, to wait for the threads.

Correctness

The range calculation works on m = n − 1 interior points. Thread t gets:

start = 1 + floor(t × m / p)
end = 1 + floor((t + 1) × m / p)

If n ≤ 0 or p ≤ 0, an IllegalArgumentException is thrown.
