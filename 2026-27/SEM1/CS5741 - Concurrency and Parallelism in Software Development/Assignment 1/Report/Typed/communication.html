The communication stage defines the data flow between the primitive tasks.

The weights are wi = ½ if i = 0 or i = n, and wi = 1 otherwise.

There is no communication between tasks. Each task needs only the shared, read-only inputs, and sends its single value once. The only communication is a global reduction:

area = h × Σ wi · f(xi)
