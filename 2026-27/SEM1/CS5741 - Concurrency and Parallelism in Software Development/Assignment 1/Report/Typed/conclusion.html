I parallelised trapezoidal-rule integration of e−x · sin(x) on [0, 10] using Foster's methodology, implemented it in Java, and checked the results against Amdahl's law.

  • Design: domain (data) decomposition, block grouping and static mapping.
  • Correctness: very good, with an error of only about 1e−13 for very large n.
  • Main result: around 7.8× speedup at n = 500m, linear speedup up to p = 4, and a very small serial part (overhead).
  • Amdahl's law showed that the limitation was the hardware.

Possible improvement

Static mapping could be replaced, since not all the cores were equal.
