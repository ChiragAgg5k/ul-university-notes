# Statecharts

## Said in class (Wed 23 Sep 2026)

> **Q:** What is the purpose of a state chart?
> **A:** To model state independent variation and behaviour.

## Note on the wording

The usual wording is state-**dependent** behaviour. A statechart shows how an object responds to the same event in different ways depending on its current state. For example, `pressPlay` starts playback when a player is `Stopped` and does nothing when it is already `Playing`. Check with the lecturer or the slides whether "independent" was misheard.
