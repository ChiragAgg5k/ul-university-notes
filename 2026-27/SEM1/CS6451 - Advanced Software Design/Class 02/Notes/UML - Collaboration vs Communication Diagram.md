# UML — Collaboration vs Communication Diagram
CS6451 — Advanced Software Design | 2026/7 SEM1 | Class 02

The term **collaboration diagram** changed meaning between UML versions.

| UML version | "Collaboration diagram" | "Collaboration" |
| --- | --- | --- |
| 1.x | An interaction diagram: objects with numbered messages between them (sequence-like, laid out spatially) | Same thing |
| 2.x | Renamed **communication diagram** | A structural concept: a set of roles cooperating to achieve a behaviour, often used to model a design pattern |

Takeaway: in UML 2, "collaboration" has nothing to do with the old message-numbered diagram. When reading older material, translate "collaboration diagram" to "communication diagram".
