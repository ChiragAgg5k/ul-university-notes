### Common mistakes to avoid

The notes are terse, so the wording after each dash is my reading of them.

1. **Name** — put your name on the slides.
2. **Structure** — cover the topic, the question, the answer and the literature review. Do not do a systematic review.
3. **Review the literature** — the talk has to draw on published sources, not opinion.
4. **Topic and question** — the topic should not be phrased as a hypothesis, and the research question must be a real question ending in "?".
5. **Format** — use the correct citation format, with a reference list. The final report asks for Harvard (author date) style, so use the same here.
