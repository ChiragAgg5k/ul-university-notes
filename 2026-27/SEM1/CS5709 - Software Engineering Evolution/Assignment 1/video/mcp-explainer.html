The stdio years

One API key, one project

claude mcp add appwrite \
  --env APPWRITE_PROJECT_ID=<YOUR_PROJECT_ID> \
  --env APPWRITE_API_KEY=<YOUR_API_KEY> \
  -- uvx mcp-server-appwrite

Switching projects meant editing your editor config.

Creating a project, or anything at organisation level, was impossible.

Authorization ate the schedule

A user's token instead of a project key

1. Request without a token → 401
2. Find the authorization server RFC 9728
3. Client registers itself RFC 7591
4. Authorize with PKCE and a resource indicator RFC 8707
5. Token issued for mcp.appwrite.io
6. Every call verified, then served

Every client read the specs differently, and we found out in production.
